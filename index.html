Phase 1 — Prototype

操作マニュアル自動生成ツール

URL あるいはページの HTML を入力すると、サイトの構成を解析し、操作マニュアル（HTML）を自動生成します。本フェーズはデータ契約を確定させるためのプロトタイプです。

01

処理フロー

1
リンク抽出
extractRoutes
2
シナリオ生成
generateScenario
3
ステップ構築
runStepsMock
4
マニュアル生成
generateManual
「実行」を押すと、ここに進捗を表示します。
02

入力

ブラウザの CORS 制約により取得できないサイトがあります。取得に失敗する場合は「HTML を貼り付け」をご利用ください（フェーズ②でサーバー側の実巡回に置き換えます）。
API キーは Gemini への通信時のみ使用し、ダウンロードする成果物には含めません。使用モデルはコードの CONFIG.MODEL で指定します。
