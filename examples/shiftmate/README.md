# シフトメイト — デモ用 SaaS サイト（テストベッド）

マニュアル自動生成ツールの動作確認に使う、**本番想定の静的 SaaS サイト**（架空のシフト管理サービス）。
飲食・小売向けのシフト管理という設定で、ログイン・ダッシュボード・シフト作成・スタッフ管理・設定など、
操作マニュアルにしがいのある画面を一通り揃えています。

## ページ構成（7枚）

| ファイル | 画面 |
|---|---|
| `index.html` | ランディング（マーケ） |
| `login.html` | ログイン |
| `signup.html` | 新規登録 |
| `dashboard.html` | ダッシュボード（週カレンダー・統計） |
| `shifts.html` | シフト一覧（テーブル） |
| `shift-new.html` | シフト作成フォーム |
| `staff.html` | スタッフ管理 |
| `settings.html` | 設定 |

`assets/app.css` が共通デザインシステムです。各ページは相対リンクで相互に行き来できます。

## Canvas でのテスト方法（ローカルから モード）

1. Gemini Canvas で **フェーズ①の `index.html`（ツール本体）** を開く。
2. 入力モードを **「ローカルから」** に切替。
3. **このフォルダ（`examples/shiftmate/`）を選択**。
4. 「実行」→ 各 `.html` がルートとして読み込まれ、シナリオ→マニュアルが生成されます。

> CORS の制約を受けず、サーバー無しで Canvas でも動きます（あなたが選んだファイルだけを読むため）。

## フェーズ②（サーバー版）でのテスト方法

ローカルサーバーで配信して URL モードで巡回するのが最も忠実です（実スクショ・JS描画も取得できます）。

```bash
# このフォルダを配信
npx serve examples/shiftmate -l 4321
# → フェーズ②アプリの URL 欄に http://localhost:4321/index.html を入力して巡回
```

※ これはデモ用のサンプルです。実在のサービスではありません。
